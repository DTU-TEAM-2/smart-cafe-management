# Đầu vào cho vòng triển khai mới

Chưa nhập SRS, project plan, phân công hoặc dữ liệu từ dự án cũ. Bổ sung đúng phiên bản hiện hành, ghi nguồn và các điểm đã được nhóm/mentor xác nhận trước khi viết tiêu chí nghiệm thu.

Các đường dẫn SRS/phân tích cụ thể trong skill kế thừa có thể chưa tồn tại ở repo này. Khi thiếu nguồn, báo rõ và hỏi phần nghiệp vụ phụ thuộc; không tạo nội dung giả để làm đầy đường dẫn.
